# Installation

This installation is pretty much taken from lazyvim

first do this which makes a backup of your current nvim files
```
# required
mv ~/.config/nvim{,.bak}

# optional but recommended
mv ~/.local/share/nvim{,.bak}
mv ~/.local/state/nvim{,.bak}
mv ~/.cache/nvim{,.bak}
```
then do this to clone the repo into nvim 

```
git clone git@github.com:NominalAnxiety/Best-Neovim-Config.git ~/.config/nvim
```
then start nvim and it should work
